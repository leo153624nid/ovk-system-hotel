# ovk-system-hotel
test job for OVK-System

Тестовое задание: «Записная книжка отеля»

Что нужно сделать

Backend на Go: REST API, регистрация и вход, CRUD по записям гостей (ФИО, телефон, номер, дата заезда, дата выезда, заметка).
Авторизация: пароль хранится хешем (bcrypt или argon2), без токена данные недоступны.
PostgreSQL: схема с миграциями, минимум один обоснованный индекс.
Frontend на TypeScript/JavaScript: вход, список записей с поиском, создание, редактирование, удаление.
Инфраструктура: README с запуском, .env.example , приветствуется docker- compose .
Качество: валидация, обработка ошибок, 2-3 осмысленных теста, осмысленные коммиты.

Что проверяем при приёмке

Проект поднимается по README за 10 минут.
Регистрация и вход работают, пароль в базе — хеш.
Запрос без токена возвращает 401.
CRUD полностью работает через интерфейс.
Поиск по записям работает.
Миграции применяются одной командой.
Тесты запускаются одной командой.
В README написано, что не успели и что сделали бы иначе.
